## 2. 模块职责说明

### com.demo
- 项目启动入口 `LibraryDemoApplication`

### config
- `SecurityConfig`：定义 Spring Security 规则，设置认证与授权

### controller
- `BookController`：图书查询、图书新增、图书更新
- `BorrowController`：借阅、归还、我的借阅记录
- `LogController`：日志查询接口

### entity
- 定义数据库对应的对象模型：`Book`、`BorrowRecord`、`OperationLog`、`SysUser`

### mapper
- 定义 SQL 映射接口，负责数据库访问

### service
- `BookService`：图书业务处理
- `BorrowService`：借阅和还书业务处理
- `OperationLogService`：日志写入与查询

### resources
- `application.yml`：系统配置
- `schema.sql`：数据库表结构初始化
- `data.sql`：初始化样例数据
- `mapper/*.xml`：MyBatis SQL 配置

## 3. 工程设计要点

### 3.1 轻量开发策略
- 使用单体架构，不拆分服务
- 使用 H2 内存数据库，不依赖外部数据库环境
- 使用 HTTP Basic 作为安全认证方案，减少 JWT 等额外复杂度

### 3.2 全产业链思维在工程中的映射
- 图书信息管理：Book 模块
- 用户与权限：SysUser + SecurityConfig
- 借阅交易：BorrowService + BorrowRecord
- 审计治理：OperationLog + LogController
- 数据与分析：MyBatis + Mapper XML + 日志表

### 3.3 扩展性说明
- 后续可增加：
  - 图书状态更细分（可预约、已损坏、已下架）
  - 用户积分或借阅规则
  - 事务补充与幂等处理
  - 分页查询
  - 统一异常处理
  - 前端页面（Thymeleaf / Vue / React）

## 4. 运行入口

```bash
mvn clean package
java -jar target/campus-library-management-system-1.0.0.jar
```

## 5. 结论

该工程设计保持简单、清晰且便于迭代。它不仅能体现 Spring Boot + MVC + MyBatis + Security 的技术组合，也能通过模块分层模拟真实业务协同场景，适合教学、演示和课程作业使用。
